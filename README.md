# Cafe Management System

## Technologies Used
- Java
- JDBC
- MySQL
- NetBeans IDE
- XAMPP

## Project Features
- Menu Management (Add, View, Update, Delete)
- Customer Management
- Order Management
- Order Items Management
- Billing Management
- MySQL Database Connectivity using JDBC
- Main Dashboard

## Project Description
Cafe Management System is a Java-based application developed to manage cafe operations such as menu management, customer records, orders, order items and billing. It uses JDBC to connect Java with MySQL database and provides basic management functionality through different modules.

## Project Modules
- `cafemanagmentsystem` – Database Connectivity
- `MenuManagement` – Menu CRUD Operations
- `CustomerManagement` – Customer CRUD Operations
- `OrderManagement` – Order CRUD Operations
- `BillingManagement` – Billing CRUD Operations
- `OrderItemsManagement` – Order Items CRUD Operations
- `MainDashboard` – Main Dashboard

## Developed Using
Java | JDBC | MySQL | NetBeans | XAMPP
